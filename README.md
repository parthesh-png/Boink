# Emilo – Mini Social Media Platform

A simple and clean full-stack Mini Social Media Platform built with the MERN stack.

## Tech Stack
- **Frontend**: React.js, Tailwind CSS, Axios, Lucide Icons
- **Backend**: Node.js, Express.js, JWT, bcryptjs
- **Database**: MongoDB (Mongoose) / MongoDB Atlas
- **Validation**: Zod (Frontend & Backend)

---

## Features
- **User Authentication**:
  - Registration & Login
  - JWT authentication
  - Password hashing with bcrypt
  - Protected routes
- **Profile Module**:
  - View & Edit profile
  - Fields: Name (min 3 chars), Email (**readonly**), Bio, Profile Picture URL
  - Follow / Unfollow user functionality
- **Post Module**:
  - Create post with text & image
  - View all posts
  - View own posts
  - Delete own posts only
  - Like / Unlike post functionality
- **Validation (Zod)**:
  - Name: minimum 3 characters
  - Valid email format
  - Password: minimum 6 characters
